  Route: /files
  API: /api/files/plan, /api/files/zip-organize
  Capabilities: Natural language organization intent, native browser File System Access API (showDirectoryPicker) live directory restructuring, duplicate copy detection, universal ZIP upload/reorganized download fallback.

Vertical_4_Lint:
  Route: /lint
  API: /api/lint/analyze, /api/lint/fix, /api/lint/github
  Capabilities: Code file upload, live scratchpad, and public GitHub URL ingestion with SSRF guards. Detects and repairs errors across JS, TS, Python, and JSON with side-by-side diffs and downloadable ZIP.
